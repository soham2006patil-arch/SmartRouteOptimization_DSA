# Smart Route Optimization DSA

A Python mini-project that calculates the shortest route between selected Maharashtra cities using Dijkstra's algorithm.

## Features

- Interactive city selection
- Dijkstra's shortest-path algorithm
- Priority queue implementation with `heapq`
- Displays the optimal route and total distance

## Available Cities

- Pune
- Mumbai
- Satara
- Kolhapur
- Sangli
- Ahilyanagar
- Nashik
- Palghar
- Chhatrapati Sambhajinagar

## Requirements

- Python 3

## Run the Project

```bash
python3 route_optimization.py
```

Enter a source city and a destination city from the available city list.
